# Guck mal! - Reise Bingo

Eine unterhaltsame Bingo-App für Kinder und Familien auf Reisen.

## Features

- 🎮 **Zwei Spielmodi**: Suche (unbegrenzt) und Jagd (Ziel-Bingos)
- 🗺️ **7 verschiedene Bereiche**: Autobahn, Land, Stadt, Zug, Kirche, Zuhause, Zoo
- 🌸 **Saisonale Items**: Unterschiedliche Items für Frühling/Sommer und Herbst/Winter
- 🎄 **Weihnachts-Special**: Schneefalleffekt und 15 saisonale Weihnachts-Items im Dezember
- 🌍 **6 Sprachen**: Deutsch, Englisch, Spanisch, Französisch, Italienisch, Niederländisch
- 📱 **Cross-Platform**: iOS und Android

## Technologie

- Flutter 3.x
- Dart
- MVVM Architektur

## Build

```bash
# iOS
flutter build ios --release

# Android
flutter build apk --release
```
