# Contributing

Bug reports and suggestions are welcome as an [issue](../../issues/new/choose);
security issues privately as described in [SECURITY.md](SECURITY.md). Pull
requests from outside are not accepted: Guck mal! is source-available for
inspection and all rights stay with the author (see [LICENSE](LICENSE)). Good
suggestions are implemented by the author.
