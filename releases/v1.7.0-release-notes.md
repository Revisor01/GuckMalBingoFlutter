## Was ist neu

- **Aufgeräumter Code** — Doppelte Übersetzungsschlüssel entfernt, ungenutzten Code gelöscht, große Dateien in kleinere Bausteine aufgeteilt
- **Bessere Performance** — Hintergrundmuster werden nur noch einmal berechnet, Animationen pausieren wenn die App im Hintergrund ist

# v1.7.0 — Tech-Debt Cleanup + Duel Mode

**Build:** 27
**Date:** 2026-04-03

## What's New

- **New Game Mode: Duel** — Play on two devices and see who finds all the things first! Each player sees individual items and taps "Found" — whoever reaches the target first wins
- **Three Game Modes** — Look! (relaxed exploring), Bingo Hunt (who gets enough bingos first?) and Duel (fast finding on two devices)
- **Unified Setup Flow** — Target count is always selected as the last step for Hunt and Duel
- **Score Display** — Yellow circles show progress in a kid-friendly way
- **Long-Press to Skip** — In Duel mode, long press prevents accidental skipping
- **Resume Games** — Interrupted Duel games can be continued on next app start
- **Cleaner Code** — Removed duplicate translation keys, deleted unused code, split large files into smaller components
- **Better Performance** — Background patterns are calculated only once, animations pause when app is in background
