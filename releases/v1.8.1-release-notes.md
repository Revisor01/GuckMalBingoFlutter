# v1.8.1 — Privacy, Rating & Duel Onboarding

**Build:** 28
**Date:** 2026-04-10

## What's New

- **English Privacy Policy** — Non-German-speaking users are now directed to the English version on simonluthe.de
- **Rate the App** — New button on the info screen (behind parental gate) that opens the store listing for a review
- **Duel in Onboarding** — The duel mode now has its own onboarding page with a two-device visualisation
- **Game State Fixes** — Game state is now correctly cleared when a game is actively left, and can no longer be wrongly restored after victory
- **iOS Build Fix** — iOS now uses the version number from pubspec.yaml instead of hard-coded values
